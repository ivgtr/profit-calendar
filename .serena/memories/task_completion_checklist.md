# タスク完了時のチェックリスト

## 必須実行項目

### 1. Lintチェック
```bash
npm run lint
```
- ESLintエラーがないことを確認
- 警告がある場合は内容を確認し、必要に応じて修正

### 2. 型チェック
```bash
npm run build
```
- TypeScriptコンパイルエラーがないことを確認
- ビルドが正常に完了することを確認

## 確認項目

### コード品質
- [ ] TypeScript型アサーション（`as`）を使用していない
- [ ] 適切な型ガード関数を実装している
- [ ] React HooksのuseCallback/useMemoを適切に使用している
- [ ] エラーハンドリングが適切に実装されている

### CSS/スタイリング
- [ ] `!important`を使用していない
- [ ] CSS変数を活用している
- [ ] BEM記法に従っている
- [ ] レスポンシブデザインに対応している（768px以下）
- [ ] 適切なz-indexレイヤーを使用している

### セキュリティ
- [ ] 秘密情報・APIキーがコードに含まれていない
- [ ] ユーザー入力の適切なバリデーション
- [ ] XSS対策が実装されている

### パフォーマンス
- [ ] 不要な再レンダリングを避けている
- [ ] 大きなデータセットに対して適切な最適化を実施
- [ ] 画像やリソースの最適化

## コミット前の注意事項
- **自動コミット禁止**: 明示的な指示がない限りコミットしない
- **自動プッシュ禁止**: 明示的な指示がない限りプッシュしない
- **.envファイルをコミットしない**
- **開発サーバーを勝手に起動しない**

## 追加推奨事項
- README.mdやドキュメントの更新（明示的に要求された場合のみ）
- 新しい依存関係を追加した場合はpackage.jsonの確認
- 破壊的変更がある場合は事前に確認
